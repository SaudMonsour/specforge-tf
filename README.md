# الاستدلال بالاقتراح والتحقق

محرك استدلال تخميني مبني باستخدام TensorFlow، بنموذج صغير يقترح البايتات ونموذج هدف يتحقق منها، مع تصحيح احتمالي والتراجع عن التخزين المؤقت عند الرفض.

دُرب النموذجان من الصفر على 151,095 بايتًا من «أليس في بلاد العجائب». يحتوي النموذج الهدف على 311,616 معاملًا، والمقترِح على 40,224. اختيرت نقطتا الحفظ بصورة مستقلة على التحقق.

تستخدم نتيجة الاختبار 15,072 هدف بايت في نوافذ لا تتداخل أهدافها. انخفاض استدعاءات النموذج الهدف لم يحقق تحسنًا في زمن التنفيذ على المعالج المركزي. عند حجم اقتراح 4 انخفضت الاستدعاءات 61.46%، بينما زاد وسيط الزمن 35.65%.

تشمل الكلفة تجهيز السياق وتوليد المقترحات والتحقق وتصحيح الاحتمال والتراجع والتزامن. تختلف جودة توزيعات العينات عن تطابق المخرجات مع البذرة نفسها؛ التصحيح يستهدف توزيع النموذج، ولا يضمن مسارًا نصيًا متطابقًا لكل بذرة.

تتضمن الأدلة 15 اختبارًا و2,560 مقارنة للرموز الجشعة، وفحص توزيع متعدد الخطوات عبر 12,000 بذرة ثابتة على نموذج مبسط قابل للحصر. لا يجوز تعميم قياسات هذا المعالج على معالجات رسومية أو نماذج أكبر.

### ملفات المشروع

| المسار | المحتوى |
| :--- | :--- |
| `specforge/model.py` | مفكّك ترميز TensorFlow وعمليات كتل المفاتيح والقيم وواجهة الخلفية. |
| `specforge/decoding.py` | تحقق مستقل عن إطار العمل وتصحيح المتبقي والتراجع. |
| `generate.py` | واجهة أوامر للتوليد بالنموذج الهدف أو بالاقتراح والتحقق باستخدام نقاط الحفظ. |
| `prepare.py`, `study.py` | إعداد النص مع فحص البصمات وتدريب بميزانية ثابتة. |
| `benchmark.py` | توقيت بترتيب تنفيذ متوازن ومعرّفات مخرجات محفوظة. |
| `sampler_check.py` | توزيع دقيق لنموذج محدود وتدقيق التكرارات ببذور ثابتة. |
| `verify.py`, `artifacts.py` | إعادة فحص الدرجات والمخرجات والمصدر وقائمة واضحة لملفات النشر. |
| `plots.py`, `figures/` | رسوم مبنية على القياسات المنفذة. |
| `runs/draft/`, `runs/target/` | الإعدادات والأوزان وخسائر نوافذ الاختبار والعينات الخام. |
| `runs/metrics.json` | درجات التحقق والاختبار وضوابط التجربة والبيئة. |
| `runs/benchmark.json` | جميع مشاهدات التوقيت الـ480 وملخصاتها ومدخلاتها ومعرّفاتها وأعداد الاستدعاء. |
| `runs/training_starts.npy`, `runs/training_history.csv` | جدول النوافذ الفعلي وملاحظات التدريب. |
| `runs/error_analysis.json`, `runs/sampler_check.json` | نوافذ الأخطاء وتشخيص آلية أخذ العينات. |
| `data/manifest.json`, `audit.json` | إسناد المصادر وفحوص التنفيذ وبصمات الملفات. |
| `tests/`, `USAGE.md` | اختبارات الصحة وعقد التكامل واستخدام واجهة الأوامر. |
